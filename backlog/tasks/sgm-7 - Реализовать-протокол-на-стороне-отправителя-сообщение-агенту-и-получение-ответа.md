## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Вторая половина реализации протокола (SGM-5): сторона отправителя. Нужен инструмент, которым можно отправить сообщение конкретному агенту по его идентификатору и получить ответ. Сначала это CLI для проверки обмена, он же станет основой оркестратора, который будет раздавать задачи сотрудникам.

Шина асинхронная, поэтому инструмент либо ждёт ответ с таймаутом, либо отдаёт ответ, когда тот придёт. Что именно нужно - по решению из SGM-5, там же формат сообщения, корреляция и ошибки.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Команда отправляет сообщение агенту по его идентификатору и печатает полученный ответ.
- [ ] #2 Ответ сопоставляется с отправленным сообщением по корреляции из протокола.
- [ ] #3 Таймаут и отсутствие ответа видны отправителю явно, без бесконечного ожидания.
- [ ] #4 Живой обмен с агентом из SGM-6 проходит по сценарию из протокола.
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [ ] #1 Живой round trip: сообщение отправлено командой, ответ агента получен, команды и вывод записаны в отчёте.
- [ ] #2 Есть автотест на отправку и сопоставление ответа без живой шины.
- [ ] #3 В README описан способ отправки сообщения агенту; изменения закоммичены, документация проекта и правила агентов актуальны.
<!-- DOD:END -->
